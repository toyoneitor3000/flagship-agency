# Victory Cars S.A.S. - Landing Page

Sitio web oficial de Victory Cars S.A.S., centro de detallado automotriz premium en Bogotá.

## 🚀 Inicio Rápido

1.  **Instalar dependencias:**
    ```bash
    npm install
    ```

2.  **Iniciar servidor de desarrollo:**
    ```bash
    npm run dev
    ```

3.  **Ver en el navegador:**
    Abre `http://localhost:3002`

## 🎨 Sistema de Diseño

El proyecto utiliza el sistema **"Victory Midnight"**.
Consulte `BRAND_MANUAL.md` para detalles sobre colores, tipografía y uso del logo.

## 📂 Estructura

Consulte `ARCHITECTURE.md` para entender la organización técnica del proyecto.

## 🖼️ Gestión de Assets

- **Logo:** El archivo maestro es `/public/logo.png`. No reemplazar por otros formatos sin actualizar el código.
- **Imágenes:** Colocar imágenes de servicios en `/public/services/` y galería en `/public/gallery/`.
